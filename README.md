# 📊 Student Learning Analytics – Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project focuses on analyzing student learning and course performance using a dataset containing **2,000+ records and 12 features**.

The objective is to explore student learning patterns, evaluate course performance, identify factors affecting student completion and dropout rates, and generate meaningful insights through data analysis and visualization.

Using Python and its data science libraries, this project transforms raw educational data into understandable visual insights that can support data-driven decision-making.

## 🎯 Objectives

- Analyze student course completion rates.
- Understand student performance and average quiz scores.
- Investigate factors associated with student dropout rates.
- Evaluate assignment submission and forum participation.
- Analyze student watch time and engagement patterns.
- Explore instructor and course performance.
- Identify meaningful trends through data visualization.

## 📂 Dataset Information

- **Dataset Size:** 2,000+ records
- **Total Features:** 12
- **Domain:** Education / Student Learning Analytics
- **Data Type:** Structured tabular data

### Dataset Features

| Feature | Description |
|---|---|
| batch_id | Unique batch identifier |
| instructor_id | Instructor identifier |
| course_id | Course identifier |
| completion_rate | Student course completion rate |
| avg_score_improvement | Average improvement in scores |
| avg_quiz_score | Average quiz performance |
| dropout_rate | Student dropout rate |
| avg_watch_time | Average learning watch time |
| assignment_submission_rate | Assignment submission rate |
| forum_activity_rate | Student forum participation |
| avg_feedback_score | Average feedback score |
| feedback_response_rate | Feedback response rate |

## 📈 Project Workflow

2. **Data Understanding:** Explored dataset dimensions, columns, and data types.

4. **Exploratory Data Analysis:** Investigated patterns and relationships among different educational metrics.
5. **Data Visualization:** Created multiple graphs to understand student performance, engagement, and course completion.
6. **Insight Generation:** Interpreted visual patterns to understand learning and course-related trends.
